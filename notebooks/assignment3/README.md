# Assignment 3: combined student-dropout analysis

The current synthesis is [student_dropout_combined.ipynb](student_dropout_combined.ipynb),
created on branch `assignment3-combined`. It contains self-contained English answers to the
assignment's ten numbered tasks. The original three-class
[student_dropout_classification.ipynb](student_dropout_classification.ipynb) is preserved.

## Run

Install the root `requirements.txt` in a Python environment and select that environment as the
notebook kernel. Start in `notebooks/assignment3/` and use **Restart Kernel and Run All**.
The input must be the original local `../../data/graduation_dataset.csv` (not committed).
The notebook accepts the source header spelling `Nacionality` or the local `Nationality` alias.

Results and experiment configurations are saved under `../../results/assignment3/combined/`
(gitignored). Report figures are saved under `../../figures/assignment3/combined/`.
Earlier assignment outputs are not overwritten. All reported numbers are generated by this
notebook, rather than copied from the source versions.

## Experimental scope

- Binary `Dropout=1` versus `Graduate=0`: 3,630 resolved records. The 794 `Enrolled` records have
  unresolved eventual outcomes and are excluded from supervised training and evaluation.
- First- and second-semester measurements, with `Debtor` and `Tuition fees up to date` excluded
  because their availability at the proposed decision time is unverified.
- Approximately 80/20 development/test split and seeded five-fold stratified group CV: identical
  retained-predictor profiles stay together, including the pair made indistinguishable by excluding
  administrative fields. No records are removed for this reason. Uses fold-fitted
  preprocessing, rare-category pooling, ANOVA selection, PCA or LDA.
- Per-model representation/hyperparameter searches for KNN, decision trees and linear/RBF SVM.
  Required ensembles use different base algorithms: tree AdaBoost and KNN bagging. Tree bagging
  and a matching single-tree control provide an additional mechanism comparison.
- Cross-course transfer with a fixed scratch/pretrained comparison, evaluated separately on
  identical target-course test students. Three-hidden-layer PyTorch DNN with CV tuning and
  training-only internal stopping, followed by full outer-training refits.
- Development AP determines the locked recommendation. A declared 20% contact capacity and
  training-OOF F2 thresholds are separate operational rules. Held-out calibration, uncertainty,
  model sizes, search/refit/prediction times and limited subgroup diagnostics are included.

No dropout dates, dated administrative histories or cohort identifiers are present. The analysis
therefore assesses retrospective discrimination among resolved outcomes; it does not establish
prospective warning before dropout, accuracy for unresolved students, or a causal benefit of support.
