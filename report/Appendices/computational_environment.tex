\section{Computational environment}
\label{app:computational-environment}

The timing experiment used Windows 11 and CPU execution on an Intel Core
Ultra 7 258V. Table~\ref{tab:software-versions} lists the recorded software
versions. Numerical libraries were limited to at most two threads. PyTorch
used two intra-operation threads and one inter-operation thread. Model
searches and bagging used one worker (\texttt{n\_jobs=1}).

Timing measurements were collected in two runs on the same computer.
LDA and AdaBoost were refitted and their batch prediction times measured
together. Search times refer to each model's development search.
